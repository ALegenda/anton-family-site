# Семейный атлас

Родственникам отправляйте полную ссылку из локального файла `family-link.txt`. Она открывает древо, итоги и форму дополнений. Ключ хранится после знака `#`. Любой, кто получил полную ссылку, может открыть сайт и переслать её дальше.

## Обновить сайт

1. Отредактируйте страницы и данные в локальной папке `family-content/`. Если вы клонировали репозиторий на другой компьютер, сохраните полную семейную ссылку в `family-link.txt` и один раз выполните `node pack.mjs --unpack`.
2. Запустите `node pack.mjs` из корня репозитория. Сборщик упакует страницы с тем же семейным ключом и новым случайным вектором инициализации AES-256-GCM.
3. Зафиксируйте изменения в `docs/` и отправьте коммит в `main`. GitHub Pages публикует каталог `/docs` этой ветки.

## Дополнения

Кнопка «Дополнить» в карточке подставляет имя родственника. Форма передаёт текст, ссылки и вложения через FormSubmit на настроенную почту владельца. Письма имеют тему «Дополнение к семейному атласу» с именем семьи. При первом получении проверьте также папку «Спам». Полученные материалы можно проверить и внести в следующую редакцию древа.

Почтовый обработчик задаёт параметр `family-contribution-endpoint` в `family-content/contribute.html`. При смене получателя подтвердите новый адрес у сервиса и проверьте доставку тестового письма с вложением.
